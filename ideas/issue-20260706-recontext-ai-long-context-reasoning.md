# 💡 [ReContext AI] Long-Context Reasoning Assistant Based on Recursive Evidence Replay

## 用户
- 研究人员和分析师
- 需要处理长文档的专业人士
- 法律从业者、技术文档审核员
- 知识管理团队

## 问题
- 现有LLM虽然支持长上下文窗口，但经常无法有效利用输入中已有的相关证据
- 长文档推理时信息丢失严重，关键细节被忽略
- 需要反复阅读和查找相同内容，效率低下

## 方案
- 基于arxiv:2607.02509v1的ReContext方法，实现递归证据重放机制
- 自动识别和提取长文档中的关键证据片段
- 在推理过程中智能重放相关证据，提升LLM的长上下文推理能力
- 提供友好的界面用于文档上传、证据追踪和推理结果展示

## 验证
- 构建包含10个长文档场景的测试集
- 与普通长上下文模型进行对比测试
- 收集用户反馈，评估推理准确性和效率提升

## 执行
- 2周内完成核心算法实现和MVP开发
- 使用Python构建后端，支持主流LLM API
- 前端采用简洁的Web界面
- 开源核心算法组件
