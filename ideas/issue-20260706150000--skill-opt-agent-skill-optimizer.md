# 💡 SkillOpt Agent - 让 AI 像训练神经网络一样持续优化自己的技能文档

---

## 🎯 用户
AI 开发者、Agent 应用构建者、企业内部工具团队

## 🚀 问题
Agent 技能目前要么是手工编写，要么是一次性生成，要么是通过松散控制的自我修订进化，都没有像深度学习优化器那样稳定地提升技能

## 💡 功能
一套完整的 Agent 技能优化框架，通过 rollout → 反思 → 编辑 → 验证 → 提升的闭环，像训练神经网络一样稳定地优化 Agent 的技能文档

## 🛠️ 方案
1. 技能文档作为 Agent 的可训练外部状态
2. 独立的优化器模型将有评分的 rollout 转化为技能文档的 add/delete/replace 编辑
3. 编辑只有在严格提升验证分数时才被接受
4. 文本学习率预算、拒绝编辑缓冲区、分阶段慢/元更新确保训练稳定
5. 零部署时推理开销，技能优化后直接使用
